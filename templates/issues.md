# Issues register

One row per open point. Updated on every turn. The status column is
what makes the loop detection work, so keep it current.

| # | Issue | Clause | Owner | Our position | Their position | Proposed trade | Status | Turns open |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |

**Status** is one of: open, with counsel, with buyer, agreed, dropped.

**Turns open** counts how many drafts the point has survived. Anything
at three or more has stopped moving on its own and needs a package or a
trade, not another round of the same argument.
